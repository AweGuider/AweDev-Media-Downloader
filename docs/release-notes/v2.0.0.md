# AweDev Media Downloader v2.0.0

## Highlights

- Renamed and restructured the app around a shared provider-adapter architecture.
- Added public Instagram Reel downloads through `yt-dlp`.
- Added all-media downloads for public Instagram posts and carousels through Instaloader.
- Added public Facebook video and Reel downloads through `yt-dlp`.
- Added public TikTok video downloads and short-share URL support through `yt-dlp` with `curl-cffi` browser impersonation.
- Updated previews and controls for image, mixed-media, and multi-item downloads.
- Added color-coded startup readiness indicators for each supported platform and media mode.
- Added an About dialog with project, issue-tracker, and AweDev links.
- Added clearer errors for unsupported Instagram Stories, Facebook posts, TikTok photo posts, and expired `tt.site` links.
- Changed the new-install download directory to `AweDev-Media-Downloads` without migrating existing saved paths.
- Renamed the GitHub repository to `AweDev-Media-Downloader` and updated the in-app project link.
- Changed the application settings identity to `AweDevMediaDownloader`; settings from the former YouTube Downloader identity are not migrated automatically.

## Scope and limitations

- Downloads one URL at a time.
- Does not support private or login-gated media.
- Does not support Facebook posts/photos or TikTok photo posts.
- Platform changes, regional availability, and automated-request rate limits can still affect downloads.
- Use the tool only for media you have the right to download.

## Source verification

Install dependencies with `python -m pip install -r requirements.txt`, then run:

```bat
python -B -m unittest discover -s tests -v
```
