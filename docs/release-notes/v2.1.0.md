# AweDev Media Downloader v2.1.0

## Highlights

- Added optional timestamped speech transcripts from source subtitles or local `whisper.cpp` transcription.
- Added optional visible-text extraction through the separately downloaded OCR component.
- Added caption and description text sidecars when source post text is available.
- Added optional folders for keeping multi-item post downloads together.
- Added a saved preference for opening the output folder after downloading.
- Prevented repeated or same-post downloads from overwriting files by using stable media identifiers and unique filenames.

## Transcription notes

- Transcription runs locally after the optional component is installed; downloaded media is not uploaded for speech recognition.
- Source subtitles are preferred when available. Otherwise, the component uses the multilingual Whisper base model with automatic language detection.
- Accuracy varies with language, proper names, mixed-language speech, accents, background audio, and recording quality. The included compact model can misrecognize Russian and other non-English speech, especially English names spoken inside another language.
- Transcription does not identify speakers, translate speech, or summarize transcripts.

## Validation

- Tested source-subtitle and local speech-transcription paths in the packaged Windows app.
- Tested optional component download and SHA-256 verification through GitHub Releases.
- Run the source test suite with `python -B -m unittest discover -s tests -v`.
